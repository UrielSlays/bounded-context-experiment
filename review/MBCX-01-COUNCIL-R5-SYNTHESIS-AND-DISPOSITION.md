## Governing conclusion

The r4 causal architecture survives review. All three seats agree that bounded obligation continuity is the primary question, mechanism selection is nested beneath it, typed-native failure must not kill the program, and the conditional same-model A→B→A screen is the correct next question after deterministic proof. The next revision is a preregistration repair, not an architectural restart.

The outside Opus seat disclosed prior-round contamination. Its repeated recommendations are not counted as independent confirmation. Its new executed attacks remain evidence. ChatGPT and Codex were fresh sealed seats.

## Adopted repairs

1. **Separate cohorts.** Freeze 240 deterministic Stage-1 scenarios and 384 disjoint Stage-2 scenarios. The paid looks remain `96 / 192 / 384`; no invented or reserve scenarios are permitted.
2. **Executable state/action contract.** Add a normative companion contract defining the bitemporal query clock, event payloads, legal transitions, restoration, scope, delegation, dependency, handoff, action enumeration, gold, serialization, and illegal outcomes.
3. **Falsifiable boundedness.** Add active-subject history depth `D = 1 / 4 / 16 / 64 / 256` alongside dormant archive `H` and frontier `F`. Charge physical work below every index abstraction; no metadata exemption.
4. **Cold-open and rebuild proof.** Count artifact open/decode/reconstruction work and add journal-to-projection rebuild equality as a seventh reconstruction witness.
5. **Producer taint isolation.** Candidate producers may read the public journal and candidate code only, never gold, reference packets, generator internals, or reference reducer modules.
6. **One selector, two meanings.** Engineering output is the measured Pareto set under frozen indifference bands. A separate deterministic carrier rule chooses the Stage-2 packet and carries no engineering recommendation.
7. **One paid cut and one call DAG.** Every Stage-2 scenario has exactly one preselected obligation-bearing cut and exactly three fresh calls per condition: `A0 -> B -> cold A1`. Primary BC versus OM therefore costs six accepted calls per scenario before transport overhead.
8. **Three scored decisions.** Scenario contract success is the conjunction of A0 target selection, B proposal correctness, and A1 reconciliation/action correctness. The conjunction length is fixed at `k = 3`.
9. **Presentation-matched OM.** BC and oracle-minimal OM use byte-identical outer schemas, keys, order, field descriptions, output schemas, and token ceilings. They differ only in which public semantic objects are included. Neither contains gold flags or answer IDs.
10. **Exact inference contract.** Freeze the exact `confseq` commit, source hashes, function, affine transform, alpha allocation, truncation, running intersection, look schedule, numerical tolerance, simulation grid, and fixtures.
11. **Inferential oracle floor.** The OM `0.80` floor is evaluated by a confidence sequence, not a point estimate. Promotion or model-interface failure requires the corresponding OM lower bound to clear the floor; an OM upper bound below the floor yields ceiling.
12. **Missingness and power.** Lower the hard missing-pair ceiling to 2%, retain worst-case assignment invariance, and require pre-paid operating-characteristic fixtures for discordance, missingness, boundary, promote, fail, and ceiling branches.
13. **Write-ahead model results.** Journal raw provider response bytes immediately after receipt and before parse/validation; recovery replays recorded bytes and never resamples an accepted call.
14. **Typed capped handoff.** Replace free-text proposal/warning channels with enumerated codes and public IDs under explicit caps.
15. **Transport closure.** Prohibit response caching, fallbacks, server-side presets/tools/transforms, and provider substitution; missing route metadata makes the pair missing.
16. **Reduce machinery.** Defer LR/EF/XT/CO to a separately authorized diagnostic extension. They cannot create the primary result and dominate the token budget.
17. **Bound Stage-1 cost.** Exactness runs once across the complete deterministic manifest. Performance repetitions run only on a frozen stratified subset, with a bounded run root and explicit cold/warm accounting.

## Rejected or narrowed suggestions

### Add snapshot-plus-bounded-tail as a fourth mechanism

Rejected as a separate semantic arm. ChatGPT and the outside seat independently found the comparator set complete; a periodic active-scope snapshot plus bounded delta tail is an FC implementation strategy because FC already owns rebuildable current pointers/status and coarse materialization. The r5 design requires FC to exercise a segmented snapshot-plus-tail implementation so the known checkpoint-overflow/full-replay footgun is tested, but it does not pretend this is a fourth semantic mechanism.

### Delete A→B→A or replace it with one call

Rejected. The original question is cold logical handoff continuity. The repair is one three-call episode per condition per scenario, not 24 paid episodes and not a one-call proxy.

### Let a lexicographic rule make the engineering recommendation

Rejected. Lexicographic carrier selection is retained only to choose a byte-equivalent Stage-2 carrier. Engineering recommendation remains a Pareto/indifference-band report, with an owner decision if no mechanism strictly dominates.
