1. Top-level verdict
NO-GO — the experiment can still choose the wrong architecture before paid inference begins.

r2 is substantially tighter than a generic memory benchmark, and several important pieces now hold: the primary effect boundary is coherent, the scorer quantum is adequate, the primitive event grammar is not itself T-shaped, the direct-runner choice removes framework confounds, and the cost gate can fail UNDERFUNDED rather than laundering a cheap null result.

But I constructed six experiment-level blockers:

F is not yet the strongest cheap deterministic flat comparator. It already stores direct prerequisite IDs but is denied cheap transitive closure over those IDs; separately, an untyped append-only public-event log plus deterministic replay solves the mandatory retraction cases that current-only F is designed to lose.

Generator composition can steer the answer. With 30 gold-positive pairs, changing only the count of typed-critical positives from one to two moves the idealized TN–F delta from 0.01695 to 0.03448, crossing the +0.03 build boundary while remaining legal under the frozen envelope.

The 512-token output contract contradicts the maximum legal response shape. Eighteen maximum-length IDs already represent 576 field-tokens before JSON overhead and before the optional ongoing choice.

The reconstruction witnesses prove artifact necessity, not artifact causality. I built a child that passes all three current witnesses while reconstructing from hidden history keyed by scenario_id.

Whole-pair invalidation plus reserve replacement can create informative-missingness bias. At the allowed 5% invalid-pair rate, losing only three TN-hostile scenarios can change a true scheduled mean below +0.03 into an observed mean of +0.08.

The variance/calibration envelope has an uncovered tail. The chi-square pilot SD bound is not a 95% bound for the explicitly retained non-normal families, and a legal asymmetric two-point distribution with SD slightly above 0.40 can miss the 80% kill-power requirement when a 12-pair pilot misses its tail.

7. Required attacks A–H
Attack A — treatment/materializer parity — EXECUTED

I constructed a multi-scope obligation world with due/near-due items, terminal suppression, and a dependency chain:

A → B → C.

r2 F's visible packet contains A and direct prerequisite B. TF's flat packet follows the same direct-only materializer. TN can expose C through native multi-hop closure.

But F's persisted rows already contain:

A.prerequisites = [B]

B.prerequisites = [C]

A trivial deterministic BFS returned:

['A','B','C'].

Therefore C is not information uniquely recoverable from a typed relation representation. It is a cheap selector over F's own identifiers.

Result: the current parity differential cannot catch this false TN win because F and TF share the same deficient direct-only materializer.

For the opposite direction, I constructed compact mock packets in which TN carries relations/evidence absent from F. Under a tight cap TN can hit budget_failure while F fits. r2's density/utilization logs do expose this rather than silently treating it as model inferiority. That portion of the design works.

Interpretation: Attack A fails r2 on comparator fairness.

Attack B — retraction/public-schema neutrality — EXECUTED

Trace 1:

assert A → correct to B → retract correction.

Current-only F ends at unknown, because A was overwritten and history was forbidden.

TF/TN restore A.

Trace 2:

open O1 → cancel O1 → retract cancellation.

Current-only F has lost the prior open state and ends unknown/inactive.

TF/TN restore O1.

Then I ran the same primitive public sequences through an untyped append-only event list with deterministic replay. It also restored A and O1.

So:

The public event grammar is not pre-solving the ontology.

Retained history genuinely matters.

Typed history is not necessary for these cases.

That distinction is critical. The current experiment turns “history beats destructive overwrite” into evidence for the typed package.

Attack C — exact scorer quantum — EXECUTED

Attack E — full decision-rule calibration — EXECUTED

First, the old conceptual threshold error is gone: +0.03 is the decision boundary and +0.08 is a planning alternative, not an observed-mean requirement.

1.5506 × s.

For an asymmetric 10% rare-tail two-point population with true mean 0.08 and SD about 0.36, a 12-pair pilot misses the rare state with probability:

When that happens, s=0, so r2 falls to s_design=0.20. Simulating the claimed upper-SD procedure under that non-normal population gave coverage only about 72%, not 95%.

9. WOULD YOU DESIGN IT DIFFERENTLY?

Yes.

The central difference is philosophical:

Do not make typed memory prove that history is useful. Make typed memory prove that typing/relationships add something after a cheap flat history already gets to remember.

r2's primary F is an excellent current-state ledger, but “current-only” is an implementation choice rather than the strongest cheap interpretation of “flat.” The experiment's owner-facing question explicitly says strongest cheap deterministic flat package. A plain append-only JSONL event history and deterministic replay meet that description more naturally than an overwrite-only reducer.

I would also make the primary estimand mechanism-standardized, not generator-mixture-dependent. For example, freeze weights for:

ordinary prospective obligation cases

update/retraction cases

cross-scope cases

dependency-closure cases

hidden-channel cases

Then a generator refactor cannot silently alter the architecture verdict by producing more of whatever TN uniquely handles.

Statistically, I would keep the simple t interval if—and only if—the complete generator-induced operating-characteristic simulation certifies it. I would not replace it with BCa merely because BCa sounds more sophisticated. The design's simulation-first instinct is correct; its support set is what needs fixing.

12. Residual risks and explicit non-claims

Even after the fixes, a positive result would establish only:

Under one frozen model/provider, workload family, action interface, and bounded payload regime, TN beat a strong flat replay package by the preregistered worthwhile margin.

It would not establish superiority over retrieval systems, learned writers/controllers, provider-native compaction, archive search, natural-language memory maintenance, cross-model conditions, general semantic memory, open-world memory, multi-agent memory, or production Muninn.

A negative result would likewise not prove that typed memory is useless. It would show only that its incremental value over the strong flat replay comparator did not justify complexity under this workload and budget.

Residuals after my proposed repairs:

synthetic-to-real ecological validity;

exact model stochasticity;

rare distributions outside the preregistered generator;

possible action-interface ceiling even with oracle memory;

final exact-tokenizer packet density;

exact provider cost;

TF mechanism precision if its subset is too small.

Those should remain explicit, not promoted into universal claims.
